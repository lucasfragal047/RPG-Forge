# RPG Forge — som sincronizado

Abra pelo servidor/Render. Para cada dispositivo, o jogador deve tocar uma vez em **Ativar áudio neste dispositivo**. Isso é necessário para o navegador liberar reprodução de áudio iniciada por eventos remotos. Depois disso, os comandos de tocar/parar enviados pelo Mestre são reproduzidos neste dispositivo.
