RPG Forge — YouTube / som sincronizado

O player usa o domínio youtube-nocookie.com e referrerpolicy=origin. Em produção, publique a mesa em HTTP/HTTPS (por exemplo, Render) para que o navegador envie o referenciador exigido pelo YouTube.

Abrir index.html diretamente por file:// não fornece HTTP Referer; nesse caso o painel informa que a mesa deve ser aberta pela URL do servidor, em vez de mostrar o erro 153.
